# 📚Shelfy 

## Web-Application
### Academic project developed with Javascript, using an organized MVC (Model-View-Controller) architecture

Welcome to our repository, featuring a web application for bookworms who love organizing their reading, 
as it works as an interactive virtual bookshelf where each book can be clicked to display its details in a pop-up.

## 🔧 Technologies:

- Node.js⚡: runtime environment

- Express.js🌐: backend framework for routes and control

- Mustache🎭: template engine for dynamic views

- HTML + CSS + JavaScript🎨: frontend structure and interactivity

- SQLite📂: lightweight relational database

 ## 🚀 Executing

 1. Clone the repository
    ``` Bash
    git clone https://github.com/Deborah-Araujo/Shelfy
    cd Shelfy
    ```
 3. Install dependencies
    ``` Bash
    npm install
    ```
 5. Run the server
    ``` Bash
    node index.js
    ```
 7. Open in your browser
    http://localhost:8080
